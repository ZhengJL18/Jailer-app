# 出题方法论（question-design）

本 skill 定义高质量选择题（MCQ）的**多阶段精炼出题**流程，供学习模式的出题管线使用。提炼自 EduAgentQG 多 agent 出题框架、REQUESTA 干扰项设计、Misconception-Aware Prompting 三套学术方法。

## 核心原则

1. **多阶段，不是一次成型**：老师出题是先有雏形、再打磨、再自查。永远不要"一次生成完整好题"。
2. **独立批判，不自审自过**：出题者自己审自己的题会天然自洽放行（"AI 自评中庸"陷阱）。必须有独立视角挑毛病。
3. **不维持答案一致**：加复杂度轮中答案随题演化，允许改变，不被"原答案唯一"锁死。
4. **画像针对性**：每道题要针对该学生的易错点和错因，不是通用模板题。
5. **去重是硬约束**：与最近出过的题雷同（尤其只换数字）= 废题。

## 复杂度维度库（加复杂度轮用）

每轮从以下维度**挑一个**加，不要重复用同一个维度。每个维度给定义 + 示例 + 如何加。

1. **多步推理**：题干从单步变成需 2-3 步推导。
   示例：已知 A 求 B → 先求中间量 C 再求 B。加：引入一个必须算出的中间量。
2. **条件分支**：需要分类讨论（不同条件不同结果）。
   示例：绝对值/分段函数/定义域讨论。加：给一个需要分情况的条件。
3. **数据干扰**：加入相似数字/单位陷阱，干扰项用"算错一步"的结果。
   示例：给半径 5，但直径/周长/面积都有陷阱值。加：选项放"把 5 当直径算"的错误结果。
4. **概念陷阱**：用易混淆概念做干扰项（misconception-aware）。
   示例：lim 与函数值、子集与真子集、必要与充分。加：干扰项=学生典型误解的结论。
5. **情境综合**：嵌套现实场景，需提取信息再解题。
   示例：购物打折 + 运费 + 优惠券叠加。加：把纯数学题包进一个多信息情境。
6. **反向设问**：已知结果求条件/求源/求反例。
   示例：已知解求参数范围、求使结论不成立的条件。加：把"正向求"改成"逆向问"。

**干扰项设计标准（REQUESTA + Misconception-Aware）**：
- 干扰项要**像真错**——学生做错时会得到的结果，不是明显离谱的答案
- 每个干扰项对应一种典型错误（算错/漏条件/概念混淆/粗心）
- 干扰项语言风格与正确答案一致（都像"标准答案"），长度相近
- 严禁"明显短/明显怪/明显大"的陪衬选项

## 难度档 ↔ 复杂度轮数映射

| 难度档 | 复杂度轮数 | 维度倾向 |
|---|---|---|
| 低 (easy) | 1 轮 | 数据干扰 或 情境综合（轻量） |
| 中 (medium) | 2-3 轮 | 多步推理 + 概念陷阱 + 数据干扰 |
| 高 (hard) | 4 轮 | 条件分支 + 概念陷阱 + 多步 + 反向设问 |

## 批判清单（独立批判轮用，EduAgentQG Solver+Educator 收敛版）

以"出题组长"视角审成品题，逐项给通过/不通过 + 具体原因：

1. **样板题/雷同**：这是不是 LLM 记忆里的最常见模板题？选项是不是一眼能猜？
2. **难度匹配**：实际解题所需步数/思维深度对得上目标难度档吗？太简单=白加复杂度，太难=超纲。
3. **干扰项有效性**：每个干扰项都对应一种真实错误吗？有没有明显错的陪衬？换数字后还成立吗？
4. **歧义/漏洞**：题干有没有歧义？条件够不够唯一解？答案是否唯一？"不维持答案一致"后有没有留下矛盾？
5. **与近 15 题撞**：和最近出过的题雷同吗（含只换数字）？
6. **画像针对性**：这道题有没有针对该学生的易错点/错因？还是换成谁都能出的通用题？

**返回格式**：`通过` 或 `不通过`，不通过时必须给出 2-5 条具体原因（每条对应上面清单某项），供回头阶段修正。

## 画像使用规则（一等公民）

出题前必须读 `0_profile.md`（学生画像）+ 最近错题，让题目带针对性：
- 学生错得多的知识点 → 优先出，且从该知识点**易错角度**切入
- 学生具体错因（如"混淆充分必要条件"）→ 用概念陷阱维度，把那个误解做成干扰项
- 学生掌握好的 → 出进阶难度（多步/反向设问）
- 画像做错才重写 → 出题时读到的总是最新针对性

## 阶段产出格式（JSON，供落库）

每阶段 LLM 输出统一 JSON：
```json
{
  "question": "题干",
  "options": ["A", "B", "C", "D"],
  "answer": "A",
  "explanation": "解析（为什么对，干扰项为什么错）"
}
```
出雏形/加复杂度/精炼都产这个 JSON；批判轮产 `{"pass": true/false, "reasons": [...]}`。
